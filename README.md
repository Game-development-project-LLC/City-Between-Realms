# City Between Realms
*A 2D narrative exploration–puzzle game set in a small city that **shifts to a different dimension every night**—each realm with its own laws.*

**One-liner:** By day you investigate the city; by night it “slides” into another realm (future, fantasy, techno-arcane, etc.). Learn each realm’s rules, solve cross-realm puzzles, and uncover the secret behind the phenomenon.

## Project Status
- Phase: Pre-production (concept & planning)
- MVP Target: 30–40 minute vertical slice covering **2–3 realms**, a compact city hub, several cross-realm puzzles, and a first reveal of the overarching mystery.

## Design Pillars
1. **Realm Contrast** – rules, aesthetics, and music shift clearly between realms.  
2. **Cross-Realm Puzzling** – progress by acting in one realm to affect another.  
3. **Readable Systems** – clear UI for realm rules (time flow, economy, tech/magic).  
4. **Personal Mystery** – the player is driven to discover *who controls the shifts and why*.

## MVP Scope
- City hub map reused across realms (blocked/unblocked paths differ per realm).  
- 2–3 key puzzles requiring realm alternation (carry info or items across).  
- A lightweight quest log, inventory, time-of-day loop (day investigation → night shift).  
- Save/load, options, basic accessibility (subtitles, color-safe UI, input remapping).
